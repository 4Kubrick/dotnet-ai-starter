# Ask the Council

1. Read `AI-GUIDE.md`, the active plan and relevant ADRs.
2. Choose 3-6 relevant specialists; include a skeptical/devil's-advocate perspective for risky decisions.
3. Ask each specialist to reason independently from repository evidence.
4. Compare agreements, disagreements, assumptions and risks.
5. Produce one synthesis: decision, trade-offs, minority view, confidence and next action.
6. If the decision is durable, propose/update an ADR under `docs/decisions/`.
